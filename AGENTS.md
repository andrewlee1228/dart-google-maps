# Agent Instructions

This document provides instructions for AI agents working with this codebase.

## About this project

This project is a Dart library that provides a wrapper for the Google Maps JavaScript API v3. This allows developers to use Google Maps in their Dart web applications.

A significant portion of the library's code is generated by scraping the official Google Maps JavaScript API documentation.

## Code Generation

The majority of the Dart code in the `lib/src/generated` directory is generated automatically. Do not edit these files directly, as your changes will be overwritten.

To regenerate the library code, run the following command from the root of the repository:

```bash
dart tool/generate_lib.dart
```

This script fetches the latest documentation from the Google Maps website and rebuilds the corresponding Dart files. If you need to make changes to the generated code, you should modify the generation script at `tool/generate_lib.dart`.

## Running Examples

The `example` directory contains numerous examples of how to use this library. To run an example, you need a web server. The `dhttpd` package is a good option for this.

1.  Install `dhttpd`:
    ```bash
    dart pub global activate dhttpd
    ```
2.  Navigate to the root of the repository.
3.  Run the web server:
    ```bash
    dhttpd --path example
    ```
4.  Open your web browser and navigate to `http://localhost:8080` to see the list of examples.

Remember to replace `API_KEY` in the example's `.html` file with your own Google Maps API key.

## Coding Style

This project follows the standard Dart coding style. The specific linting rules are defined in the `analysis_options.yaml` file. Please ensure that your code adheres to these rules.

You can check your code for style issues by running:

```bash
dart analyze
```
